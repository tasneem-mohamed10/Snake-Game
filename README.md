# 🐍 Snake Game

## 📌 About The Project
Snake Game is a simple console-based game developed using Python. The player controls a snake to eat food, grow longer, and avoid hitting the walls or itself.
## ✨ Features
- Control the snake using arrow keys.
- Eat food to increase the snake's length.
- Random food generation.
- Game over when the snake hits the wall or itself.
## 🛠️ Technologies Used
- Python
- Random Module
- Curses Library
## 🎮 Controls
- Up Arrow: Move Up
- Down Arrow: Move Down
- Left Arrow: Move Left
- Right Arrow: Move Right
## ▶️ How to Run
Run the following command:
```bash
python snake.py
```
**Note:** The game uses the `curses` library and is designed for a terminal environment that supports it.
